## 二、87.5% 不是检索错，这次能证明了

离线基线里 `F-02`（"工作餐补贴每天多少？需要发票吗？"）要点判为不命中。

但同一份报告里 **召回率@3 = 100%、MRR = 0.93**：命中的块排在第 1 位，块里写的是
**"不需提供发票"**，而用例的 `must_include` 是 **"不需要"**。两个词差一个字，严格关键词判定就判了不命中。

这个拆分的价值在于**结论是确定的**：

- 召回层没问题（块第 1 位被捞出），所以不用去调分块参数、不用换 embedding 模型；
- 问题在**用例标注的措辞**，把关键词对齐为原文"不需"，命中率就是 8/8；
- 它同时证明关键词判定不是"糊弄的"——连"不需要/不需提供"这种差异都抓得住。

只有单一"命中率"时，你看到的是"掉了"，然后开始乱调；分两层之后，改哪一层是明确的。
**这里保留 87.5% 并如实说明，比手动改成 100% 更可信。**

## 三、验收口径

| 指标 | 口径 | 方向 |
|---|---|---|
| 召回率@k | 正例中 `expected_clause` 进入前 k 条的比例 | 越高越好 |
| MRR | 预期条款名次倒数的平均值 | 越高越好 |
| 检索命中率 | 正例中 `must_include` 要点全部出现在召回块里的比例 | 越高越好 |
| 引用命中率 | 召回块所属文档与 `expected_source` 一致的比例 | 越高越好 |
| 拒答率 / 误拒率 / 含糊率 | **不在离线基线内**——拒答是 LLM 生成行为，需线上 `--mode chat` | — |

回归门禁阈值与执行方式见 `docs/03` 第六节；基线文件是 `eval/baseline/offline.json`。

## 五、一条命令复现全部离线基线

```bash
pytest -q
python -m ops.release --dir data/sample --ignore 本地检索P50_ms,本地检索P95_ms
python -m pipeline.tables --dir data/sample --query "出差天数=9"
```

想逐项看明细，再跑：

```bash
python -m pipeline.ingest --dir data/sample --dry-run --dump chunks.jsonl
python -m pipeline.quality --dir data/sample
python -m pipeline.versioning --dir data/sample
python -m eval.offline --chunks chunks.jsonl --cases eval/cases/enterprise_policy.json \
  --summary-json eval/report/offline.json
python -m eval.regression --baseline eval/baseline/offline.json --current eval/report/offline.json
```

业务指标需要真实交互日志（POC 阶段没有），用一条样例日志即可验收计算口径：

```bash
python -m ops.insights --log data/interactions.example.jsonl --price-in 0.002 --price-out 0.008
```

## 六、已知边界（不吹的部分）

- 离线基线用的是字符 bigram 朴素检索，远弱于 WeKnora 的向量 + BM25 混合检索，只用于回归对比；
- 评测用例为脱敏等价问法，不代表真实问题分布，指标不对外承诺；
- 当前只处理 Markdown/纯文本；docx/pdf 由 WeKnora 解析器负责，本地的密级/版本/体检对它们无效，
  需 `--allow-passthrough` 显式放行；
- 表格只整表保留，未做结构抽取，跨表计算题仍会答错；
- 版本与密级都从正文元信息抽取，填错就判错，未接文档管理系统；
- 权限过滤只在 search 评测链路；chat 侧需在问答服务套同一份策略清单；
- badcase 回流不自动判定对错，正例必须人工补 `must_include` 才允许入集；
- 表格结构化只处理 Markdown 表，合并单元格/多行表头不猜；查询只做等值/区间/包含；
- 旧块清理只出计划（changed/removed 清单），删除仍需在 WeKnora 管理端/API 执行；
- 业务指标是代理口径（首次解决率 = 有用 + 未转人工 + 未重复），未接工单系统；
- CI 里忽略延迟类指标：共享机器噪声大，按倍数阈值会误报。
